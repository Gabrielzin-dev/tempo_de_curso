# Gabriel & Leonardo — Portfólio Profissional 💼

Projeto desenvolvido em **HTML, CSS e JavaScript** como trabalho do **Curso Técnico em Desenvolvimento de Sistemas — PROZ (2025–2026)**.

O objetivo do projeto é apresentar um portfólio moderno, responsivo e interativo, aplicando conceitos fundamentais de desenvolvimento web e lógica de programação.
